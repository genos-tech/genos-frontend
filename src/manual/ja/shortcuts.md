## Mac と Windows/Linux のキー

ショートカットに修飾キーが使われている場合、Mac のキーと Windows/Linux のキーは異なることが多くあります。以下では、それぞれのショートカットに両方を記載しています。「設定 > ショートカット」には、お使いのコンピューター向けの同じ一覧が表示されます。この一覧は読み取り専用で、ショートカットは変更できません。

## Genos のどこでも

- Cmd-K(Ctrl-K): スポットライトを開きます。Genos のページでは、代わりにそのページ自身のボックスにカーソルが移ります。
- Escape: いちばん上にあるものを閉じます。メニュー、ウィンドウ、またはウィンドウの中にある @ のリストです(@ のリストが先に閉じます)。
- Genos の各部分を切り替える: Cmd(Windows/Linux では Alt)を押したまま Ctrl をタップします。タップするたびに、受信箱、チャット、タスク、ノート、Genos、To-Do を、最後に使った順に移動します。1 回タップすれば、直前にいた場所に戻れます。Shift を加えると逆順に進みます。押さえているキーを離すと切り替わり、Escape を押すとその場にとどまります。
- Cmd-Z(Ctrl-Z): 「元に戻す」のメッセージが表示されている間、削除を取り消します。
- ノートのページで /: ノート一覧の絞り込みボックスに移動します。テキスト欄に入力している間は何も起きません。

## 操作へ直接ジャンプする

Mac では Ctrl と Cmd を一緒に押したまま(Windows/Linux では Ctrl と Alt)、文字キーを押します。

- T: タスクを開いて、新規タスクを作成します。
- N: ノートを開いて、マイノートに新規ノートを作成します。
- X: To-Do リストを開きます。
- C: コンパクトカレンダーを開きます。
- M: 新しい Meet リンクをクリップボードにコピーします。
- H: 履歴を開きます。
- G: プレビューしているタスクのタスクグラフを開きます。

Windows と Linux では、エディターやテキスト欄に入力している間、これらの文字キーのショートカットは何もしません。そうすることで、エディターが自分の Ctrl+Alt キーを使えます(Ctrl+Alt+C でコードブロックを作ります)。

## スポットライト / Genos のボックスで

- 上 / 下: 結果の間を移動します。
- Enter: 選択中の結果をプレビューで開きます。結果が選択されていなければ、Enter で質問が Genos に送られます。
- Shift-Enter: 長い質問の中で、送信せずに改行します。
- 結果を Cmd-クリック(Ctrl-クリック): プレビューではなく、ページ全体を開きます。

## チャットで

- Cmd-Enter または Ctrl-Enter: 送信します。どのコンピューターでも、どちらのキーでも使えます。Enter だけだと改行されるので、書きかけのメッセージが誤って送られることはありません。
- スレッドの返信やタスクのコメントも、同じキーで送信します。
- メッセージを Cmd-クリック(Windows/Linux では Alt-クリック): 会話を離れずに、そのスレッドを開きます。
- Cmd-Shift-左/右(Windows/Linux では Alt-Shift-左/右): チャットのタブを移動します。チャット一覧の中を移動するには、代わりに上/下を使います。これらは、欄に入力している間は何もしません。

## タスクを作成する

- クイック追加の行: Enter でタスクを作成し、Escape でその行を消します。
- 完全な新規タスクのフォーム: Mac では Cmd-Enter、Windows/Linux では Ctrl-Enter です。チャットと違い、それぞれのコンピューターで使えるのはそのキーだけです。

## タスクテーブル

Tab でテーブルの中へ、またテーブルの外へ移動します。テーブルの中では次のとおりです。

- 矢印キー: セルの間を移動します。
- Home / End: 行の最初または最後のセルへ移動します。Ctrl+Home / End: テーブルの最初または最後のセルへ移動します。
- PageUp / PageDown: 1 ページ上または下へ移動します。
- Enter または Space: セルのエディターを開きます。Esc: 保存せずにエディターを閉じます。

## タスクボード

Tab で列の間を移動します。止まる場所は列ごとに 1 か所です。ボードの中では次のとおりです。

- 矢印キー: カードと列の間を移動します。
- Home / End: 列の最初または最後のカードへ移動します。Ctrl+Home / End: ボードの最初または最後のカードへ移動します。
- Enter: カードのプレビューを開きます。
- Space: カードを持ち上げます。そのあと矢印キーで移動し、Space で置き、Esc で取り消します。

## カレンダー

Tab でカレンダーの中へ、またカレンダーの外へ移動します。月表示では止まる場所は 1 か所です。週表示と日表示では、日ごとに 1 か所ずつ止まります。

- 矢印キー: 日と週の間(月表示)、または予定と日の間(週表示と日表示)を移動します。
- Home / End: 週の最初または最後の日(月表示)、またはその日の最初または最後の予定(週表示と日表示)へ移動します。
- PageUp / PageDown: 前の月または次の月へ移動します(月表示)。
- Enter: その日の予定、または予定を開きます。予定のない日では、Enter で新しい予定を作成します。
