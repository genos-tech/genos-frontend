## ノートの置き場所

- **マイノート**: あなただけが見られるノートです。フォルダとサブフォルダで整理できます。
- **チームノート**: チームのフォルダです。フォルダごとに、使える人を設定します。**チームに公開**にすると、チームメイトなら誰でもそのフォルダを読み書きできます。**制限付き**にすると、あなたが選んだ人だけに限られます。サブフォルダは親の設定を引き継げ、フォルダの中のノートはすべてそのフォルダの設定に従います。
- **自分と共有**: 他の人があなたに共有したノートです。
- **タスクノート**: タスクに添付されたノートです。プロジェクトのメンバーが読み書きできるので、計画を作業のそばに置けます。
- **チャットノート**: チャットやスレッドに添付されたノートで、議事録や決定事項の共有に使います。チャットの参加者が読み書きできます。
- ノートやフォルダに星を付けると、**お気に入り**に追加されます。

## 編集

- エディターはブロックエディターです。見出し、箇条書き、番号付きリスト、チェックボックス、コードブロック、表、画像が使えます。人を @メンションしたり、テキストにコメントを付けたりもできます。
- ノートはリアルタイムで共同編集されます。複数の人が同時に編集でき、互いの変更がその場で見えます。
- **バージョン履歴**には、以前のバージョンが残ります。選ぶとプレビューでき、必要なら復元できます。復元すると新しいバージョンが追加されるので、何も失われません。復元できるのは、ノートのオーナーとエディターだけです。
- **ノートテンプレート:** 新規ノートのメニューには、組み込みのテンプレートと並んでチームのテンプレートが表示されます。テンプレートは、フォルダの初期テンプレートにもできます。

## インポートとエクスポート

- **Markdownをインポート…**は、.md ファイルからノートを作成します。**フォルダ全体**を選ぶと、Notion のエクスポートのようなフォルダツリーを取り込めます。サブフォルダはすべてノートフォルダになり、Markdown ファイルはすべてノートになり、画像も一緒に取り込まれます。
- お使いの Genos で HTML ページが有効な場合、同じダイアログで .html ファイルも受け付け、HTML ページとして保存します。
    - ページはサンドボックス内で表示され、ノートエディターでは編集できません。
    - スクリプトや他のアドレスから読み込むスタイルなど、サンドボックスがブロックする部分は、インポート時に一覧表示されます。
    - HTML ページには Core プラン以上が必要です。プランごとに、1 ページのサイズ上限と HTML ページの保存容量があります。
- **Markdownとしてエクスポート**は、ノート 1 件を保存します。**フォルダを .zip でエクスポート**は、フォルダ全体を、画像付きの Markdown ファイルとして保存します。この zip は、そのままインポートし直せます。

## 共有とアクセス

- ノートの**共有**で、チームメイトを**編集者**(ノートを変更できる)または**閲覧者**(読むだけ)として追加します。人の追加と削除ができるのは、オーナーだけです。
- 見られないノートを開いたときは、**アクセスをリクエスト**を使います。オーナーの受信箱にリクエストが届き、そこで承認できます。
- 検索(Cmd+K または Ctrl+K)は、読めるすべてのノートが対象です。
