## すばやく動く

- **Cmd+K(Ctrl+K)** で、どこからでもスポットライトを開き、検索したり Genos に質問したりできます。
- 文字キーのショートカットは、Mac では Ctrl+Cmd+文字、Windows と Linux では Ctrl+Alt+文字です。
    - **T**: タスクを開いて、新規タスクを作成する
    - **N**: 新しいマイノートを作成する
    - **X**: To-Do リストを開く
    - **H**: 履歴を開く
    - **G**: プレビュー中のタスクのタスクグラフを開く
    - **C**: カレンダーを開く
    - **M**: 新しい Google Meet のリンクをコピーする

    Windows と Linux では、テキスト欄に入力している間は何もしません。

- **Cmd を押したまま Ctrl をタップ**(それ以外では Alt と Ctrl)すると、Genos、受信箱、チャット、タスク、ノート、To-Do を順に切り替えられます。
- **Cmd+Z または Ctrl+Z** で、「元に戻す」のメッセージが表示されている間、削除を取り消せます。
- ノートのページで **/** を押すと、ノート一覧の絞り込みボックスに移動します。
- **Cmd+Enter または Ctrl+Enter** で、メッセージやコメントを送信でき、新規タスクのフォームではタスクを作成できます。
- タスクテーブル、スプリントボード、カレンダーは、キーボードで操作できます。Tab で中に入り、矢印キーで中を移動します。
- 「設定 → ショートカット」に、すべてのショートカットの一覧があります。この一覧は読み取り専用で、ショートカットは変更できません。
- Genos のリンクをメッセージに貼り付けて、クリックすると、ページの上にプレビューが開くので、作業の流れを失いません。
- スレッドで**このスレッドに紐づく新規タスク**を使うと、「これはやったほうがいいね」という会話を、追跡できる作業に変えられます。スレッドに紐づけられるタスクは 1 つです。
- スプリントボード、タスクテーブル、タスクグラフは、同じタスクの 3 つのビューです。そのときに合うものを使ってください。

## 何かおかしいときは

- **通知が届かない?**
    - 「設定 → 通知」を開きます。通知がオンになっていること、一時停止されていないこと(一時停止中の人のアバターには月のマークが付きます)、ブラウザの許可が「権限付与済み」になっていることを確認します。
    - チャットや項目がミュートされていないか確認します。
    - iPhone では、Genos をホーム画面にインストールして、そこで通知を許可します。
- **プロジェクト、グループチャット、ノートが見えない?** メンバーではない可能性があります。オーナーに追加してもらうか、**参加をリクエスト**や**アクセスをリクエスト**が表示されていれば、それを使います。
- **表示が古い気がする?** タブを再読み込みします。別の場所から別のチームにサインインしたタブにも再読み込みが求められます。ブラウザでアクティブにできるチームは 1 つだけだからです。
