## AI アプリを接続する(API キー不要)

Claude や ChatGPT などの AI アプリに、あなたとして Genos で作業させられます。アプリはあなたの Genos アカウントでサインインするので、API キーは必要ありません。接続を承認するときに、アプリが使えるチームと、できることを選びます。削除は、チェックを入れない限りオフのままです。

いちばん手早いのは、「設定 → Developer → 接続済みアプリ → **AI を接続する**」です。アプリごとにタブ(Claude Code、claude.ai と Desktop、ChatGPT)があり、それぞれ手順と、貼り付けるアドレスがそのまま載っています。アプリが接続済みかどうか、最後に Genos で何かをしたのがいつかも表示されます。

アドレスは `https://<your Genos API address>/api/public/v1/mcp/core` のような形です。パネルからコピーしてください。末尾のパスを含めたアドレス全体を貼り付け、末尾にスラッシュや余計な文字を付けないでください。パスが欠けていると、Claude はサインインしたと言ったあとで、Genos がリクエストを拒否したと報告します。

**Claude Code**

1. Claude Code のチャットで、パネルに表示される 2 つのコマンドを実行します。Genos のプラグインが追加されます。
2. /mcp を実行して Genos にサインインし、チームと、Claude に許可する内容を選びます。
3. /genos:setup を実行します。接続を確認し、「はい」と答えると、Genos のルールをメモリーファイルに保存します。

プラグインが不要な場合、パネルにはターミナルで実行する 1 行のコマンド `claude mcp add --transport http genos <address>` も表示されます。これで Genos だけを接続できます。プラグインを入れると、/genos:catchup のように名前で呼び出せる、用意済みのスキルが加わります。

**claude.ai と Claude Desktop**

1. Claude で Customize を開き、Connectors を開きます。ディレクトリから Genos を追加します。まだ載っていない場合は、Add custom connector を選んでアドレスを貼り付けます。
2. Claude に求められたら、Genos にサインインします。チームと、Claude に許可する内容を選び、**許可**を押します。

代わりにプラグインを追加するには、パネルから zip をダウンロードし、Customize の Plugins からアップロードします。

**ChatGPT**

Genos は ChatGPT のディレクトリに掲載される予定です。掲載されるまでは、カスタム MCP サーバーを使えるプランの ChatGPT で、アドレスを指定して追加し、OAuth でのサインインを選びます。そのあと Genos にサインインして**許可**を押します。この方法は、ChatGPT ではまだ端から端までの動作確認ができていません。

**知っておくこと**

- AI アプリの接続には、Core プラン以上が必要です。無料プランでは、承認ページに「現在のプランでは利用できません」と表示されます。以前に接続したアプリは「一時停止中」と表示され、Core 以上にすると再び動きます。
- アプリを承認する前に、Genos はパスワードの再入力を求めます(「ご本人確認」)。10 分間は、再度求められません。Google や GitHub でサインインするアカウントにはパスワードがないので、求められません。新しいアプリがアカウントに接続されたときは、Genos からメールも届きます。
- アプリは、「設定 → Developer → 接続済みアプリ」で管理します。アプリごとに、できることの変更、チームの追加や削除、既定のチームの選択ができ、**取り消す**も押せます。取り消したアプリは、次のリクエストから動かなくなります。
- アプリに見えるのは、選んだチームの中であなたに見えるものだけです。
- お使いの Genos で AI クレジットが使われる設定の場合、AI アプリによる検索は、Genos での質問と同じようにクレジットを消費します。クレジットが残っていなくても、検索は通常の検索として回答します。

## このページの対象

このページは、Genos をほかのもの(AI アプリ、スクリプト、別のサービス)につなぐ人のためのものです。上のセクションにプログラミングは要りません。当てはまらない場合は、このページを読み飛ばしてかまいません。Genos の他の機能は、このページに依存していません。

AI アプリや API キーは、接続した人、または作成した人として動くので、その人に見えるものしか見えません。リアルタイムのストリームは、サインインしている人として動きます。Webhook は例外です。チームのオーナーかエディターがチーム全体のために設定し、誰が作成したかにかかわらず、そのチームのイベントを運びます。

## スクリプトと自動化(API キー)

ここからこのページの終わりまでは、API キーを使う方法です。Genos にサインインできないスクリプト、別のアプリ、AI エージェント向けです。

## キーを取得する

- キーは「設定 → Developer → APIキー」で作成します。キーが表示されるのは、作成したときの 1 回だけです。あとから読み返せないので、そのときにコピーしてください。キーはいつでも取り消せて、取り消すと次のリクエストから動かなくなります。
- Read か Read & write を選びます。Read のキーは、あなたに見えるものが見えるだけで、何も変更しません。Read & write のキーは、作成や更新もできます。
- その画面で作ったキーは個人用です。所属するすべてのチームで、あなたとして動くので、リクエストのたびに対象のチームを指定する必要があります。1 つのチームに紐づくチームキーは、API からしか作れず、作れるのはチームのオーナーかエディターだけです。オーナーとエディターは、「チームの API キー」にすべてのチームキーが表示されます。

詳しくは「API キーと Webhook の手順」を参照してください。

## どれを使うか

- **REST API**: 必要なときに Genos のデータを読んだり作成したりする、スクリプトや別のアプリ向けです。プロジェクト、そのタスク、個別のタスクの作成と更新を扱えます。レポート、インポート、スケジュールで動かすものに使います。
- **Webhook**: Genos から知らせてほしいときに使います。チームのオーナーかエディターが、公開された https のアドレスを Genos に教えます。Genos は、タスクが変わったとき、または選んだチャンネルにメッセージが届いたときに、そこへ送信します。
- **API キーを使う MCP**: サインインできない AI エージェント向けです。Genos を、`https://<your Genos API address>/api/public/v1/mcp?team_id=<your team's id>` の HTTP MCP サーバーとしてエージェントに追加します。疑問符の前にスラッシュは付けません。ヘッダー `Authorization: ApiKey <your key>` を送ります。方式は Bearer ではなく、ApiKey という語です。チームキーには `team_id` の部分は不要です。MCP には Core プラン以上が必要です。
- **リアルタイムのストリーム**: ダッシュボードや、メッセージが届いた瞬間に反応するボットなど、ライブで動くもの向けです。メッセージ、リアクション、既読、オンラインの人など、Genos のアプリが使っているのと同じライブのイベントを運びます。サインインには、API キーではなく Genos のログインを使います。人がサインインしている場面ではリアルタイムを、サーバー同士の通信には Webhook を使ってください。

## AI アプリにできること

「AI を接続する」パネルのアドレス(末尾が `/mcp/core`)では、日々の作業用の 34 個のツールがアプリに提供されます。タスク、コメント、ノート、マイルストーン、受信箱、メンション、To-Do、カレンダーの予定です。完全なアドレス(末尾が `/mcp`)では、110 個のツールの全カタログが使えます。そのうち 6 個は、対応する機能が Genos で有効な場合にだけ表示されます。Read のアクセスではアプリは読むだけで、「変更を行う」を許可すると書き込めます。削除には、別のチェックが必要です。

## 動作を確認する

まず `GET /api/public/v1/me/` を呼びます。人物、キーの名前とスコープ、キーのチームが返ります。個人用のキーでは、チームは空です。これは、リクエストごとに自分でチームを指定する必要があるという意味です。

- 「設定 → Developer」の**API ドキュメントを読む→**のリンクで、Genos Developers のページが開きます。REST API、MCP、Webhook、リアルタイムのイベントの完全なリファレンスで、例も載っています。

## そのほかの連携

- Google: Google カレンダー用に、「設定 → 連携」で接続します。
- GitHub: プルリクエストをタスクに紐づけるために、「設定 → 連携」で接続します。
- Slack、Notion、Jira、Asana とのライブの連携はありません。インポートはできます。タスクは CSV、Jira、Notion のエクスポートから(プロジェクトのメニューの**CSVからタスクをインポート…**)、Notion のエクスポートフォルダ全体はノートとして(ノート → インポート → **フォルダ全体**)、チームのオーナーなら Slack のエクスポートをグループチャットとして(チームプロフィールの**Slack からインポート…**)取り込めます。
