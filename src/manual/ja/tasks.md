## プロジェクト

プロジェクトにはタスク、マイルストーン、スプリントがまとまり、専用のチャットもあります。作成するには、タスクのサイドバーで**新規プロジェクト**を選びます。パブリックプロジェクト(チームの全員が見られる)かプライベートプロジェクト(メンバーのみ)を選びます。プライベートプロジェクトは非表示にもでき、その場合は存在そのものがメンバーにしか見えません。プロジェクトにはそれぞれ短いコードがあり、タスクには WRD-12 のように読みやすい ID が付きます。

- **タスク項目をカスタマイズ**では、新しいタスクとマイルストーンについて、必須にする項目とその初期値を決めます。変更できるのはプロジェクトのオーナーとエディターだけです。
- **カスタムフィールド**(タグ、文章、日付、メンバー)は、プロジェクト内のすべてのタスク、サブタスク、マイルストーンに適用されます。タスクパネルに表示され、テーブルの列としても使えます。管理できるのはオーナーとエディターです。
- **ステータスと自動化**(プロジェクトの「…」メニュー、オーナーとエディター)では、プロジェクト独自のステータスに名前と色を付けられます。**ステータスを設定**すると **In Review** を含む標準のステータスが追加され、その後は追加、名前の変更、色の変更、並べ替え、デフォルトの指定、オフ(In Review、進行中、保留、Rejected)、削除ができます。どのステータスも未着手、進行中、ブロック中、保留、完了、Rejected のいずれかに属し、ボードの列、フィルター、自動処理はこの分類を使います。自動化ルールはまだありません。
- **テンプレート**: プロジェクトのメンバーなら誰でも、そのプロジェクト用のタスクとマイルストーンのテンプレートを追加できます。
- **ラベル**: プロジェクトラベルを使うと、タスクのサイドバーでプロジェクトをグループにまとめられ、ラベルで絞り込めます。
- **CSVからタスクをインポート…**は、CSV ファイルからタスクを取り込みます。Jira や Notion のエクスポートは自動で認識され、Jira の JSON エクスポートならコメントも取り込まれます。インポートできるのは、プロジェクトのオーナーかエディターだけです。
- **アーカイブ**: オーナーはプロジェクトをアーカイブできます。内容はすべて残りますが、アーカイブを解除するまで読み取り専用になります。

## タスク

- タスクには、ステータス(未着手、進行中、保留、ブロック中、完了、Rejected。プロジェクトで設定した場合はその名前で表示)、優先度、Effort(作業量)、担当者、任意のコラボレーター、開始日と締切、タグ、説明があります。コラボレーターはプロジェクトのメンバーである必要があります。
- **Rejected** は、そのタスクを行わないことを表します。終了していますが完了ではありません。進捗バーから外れ、サブタスクは(すでに完了していなければ)Rejected として扱われ、ほかのタスクをブロックしなくなります。
- タスクには、コメント、ノート、添付ファイル、アクティビティの 4 つのタブがあります。アクティビティにはタスクへのすべての変更が記録され、そこから以前の説明に戻すこともできます。
- **サブタスク**: 作業はサブタスクに分けられます。タスクのページには、その下にあるサブタスクが表示されます。
- **依存関係**: 依存関係の欄で、そのタスクが**によってブロックされました**(ブロックしているタスク)と**ブロッキング**(ブロックされるタスク)を設定します。同じチームの別プロジェクトのタスクともリンクできます。未完了のブロッカーがある間、Genos はタスクをブロック中にします。最後のブロッカーが完了すると、未着手に戻ります。これは、ステータスがまだブロック中のときだけです。自分で別のステータスにした場合、Genos は何もしません。
- **タスクグラフ**: タスクのツリーと依存関係を表示します。**タスクグラフを開く**から、またはプレビューでタスクを開いているときに Mac では Ctrl+Cmd+G(それ以外では Ctrl+Alt+G)で開けます。
- **タスクの重要度(1〜25)**: 優先度と時間的な切迫度を組み合わせた値で、Effort が大きいほど早い段階から切迫度が上がります。「次にやること」の**重要度順**と**重要度の高いタスク**の並びに使われます。**チームの稼働状況**と**ペース**では、プロジェクトの負荷と仕事の進み具合を確認できます。
- **コメント**: コメントでは @メンションとリアクションが使えます。

## マイルストーン、スプリント、ビュー

- **マイルストーン**: マイルストーンは、ひとつの目標に向けてタスクをまとめ、進捗を表示します。タスクを割り当てたら、**マイルストーンを開始**と**マイルストーンを完了**を使います。マイルストーンはフォルダーに入れられ、星を付けてお気に入りにもできます。
- **スプリント**: **スプリント設定**で、プロジェクトのスプリントの長さと開始曜日を決めます。今後のスプリントを自動で作成することもできます。
- **ビュー**: **スプリントボード**は、タスクをステータスごとの列で表示します。**タスクテーブル**は、並べ替えと絞り込みができる表です。どちらもキーボードで操作できます(「設定 → ショートカット」を参照)。
- **保存されたフィルター**: **保存されたフィルター**は、今の絞り込み条件に名前を付けて保存します。プロジェクトの全員が使えます。
- **クイック追加**: タスクテーブルのクイック追加では、タイトルだけでタスクを作れます。プロジェクトの必須項目もそこで求めたいときは、「設定 → タスク → クイックタスク作成」をオンにします。

## GitHub と Google カレンダー

- GitHub は「設定 → 連携」で接続します。お使いの Genos で GitHub アプリが有効な場合は次のとおりです。
    - チームのオーナーかエディターが、チームに Genos の GitHub アプリをインストールします。
    - そのあと、各自がアプリを承認します。
    - アプリは読み取り専用で、コードにはアクセスできません。見えるのは、チームのインストールで選ばれたリポジトリだけです。
    - 以前の GitHub 接続は旧式の接続として表示され、**再接続**が出ます。
- プルリクエストのリンクをタスクのリンク欄に貼ると、その状態とチェックの結果をタスク上で確認できます。
- 「設定 → タスク」の**PRがマージされたら担当タスクをClose**は、ブランチ名にタスク ID を含むプルリクエストがマージされたとき、あなたが担当のタスクを完了にします。新しいアカウントでは初期状態でオンです(以前のアカウントは各自の選択のままです)。
- 「設定 → タスク」の**タスクの締切を自動同期する**は、締切のあるタスクを終日の予定として Google カレンダーに追加します。同期は一方向のみで、Google 側で予定を削除してもタスクは変わりません。
