## 設定を開く

左のサイドバーの設定をクリックします。スマートフォンでは、その他をタップしてから設定をタップします。設定は今の画面の上に重ねて開くので、作業の流れを失いません。タブは 14 個あり、順に、一般、プランと使用状況、AIクレジット利用、Genos、チャット、タスク、通知、メンショングループ、カスタム絵文字、ショートカット、セキュリティ、アカウント、連携、Developer です。このマニュアルの「設定 A-Z」のページには、すべての設定が、誰が変更できるか、必要なプラン、初期値とともに一覧になっています。

## 一般

- **外観:** テーマ(ライト、ダーク、システム。システムは端末に従い、端末の変更に合わせて切り替わります)、カラーテーマ(アクセントカラー)、行の密度(リストやテーブルの行の高さ)。
- **言語:** English、日本語、Español、Français、中文、हिन्दी。Genos もこの言語で答えます。まだ翻訳されていない文章は英語で表示されます。
- **サイドバー:** 左のサイドバーの受信箱、チャット、タスク、ノート、To-Do の表示と非表示を切り替えます。Genos は常に表示されます。この設定はお使いのデバイス間で同期されます。
- **プライバシーと分析:** 利用データを共有する。同意するまではオフです。

## プランと使用状況

現在のプラン、各上限の残り、そしてプランのアップグレード、切り替え、解約や請求を管理を開くためのボタンです。チームプランのセクション(チーム全体の席数ごとの課金)が見えるのは、チームオーナーだけです。提供されている場合は、ここで 1 回限りのクレジットパックを購入できます。購入したクレジットは期限切れになりません。

## AIクレジット利用

あなた自身の AI クレジットです。残りの数、今月の使用量、どの機能が使ったか、最近の課金が表示されます。お使いのプランがクレジットではなく 1 日あたりの AI リクエスト数で数えている場合は、このタブにその旨が表示されます。

## Genos

AI の設定です(このタブは以前、スポットライトという名前でした)。

- AIモデル(または Effort)
- Genosの回答(AIによる回答とウェブ検索)
- Genosの書く量
- Genos Assist スケジュール
- Genosが記憶していること
- スキル

スキルのカードは、お使いの Genos でスキルが有効な場合にだけ表示されます。それぞれの内容は、このマニュアルの Genos AI のページを参照してください。

## チャット

- **メッセージレイアウト:** バブルかコンパクト。
- **クイックリアクション:** ワンクリックで使える 3 つの絵文字。
- **メッセージのアクション:** メッセージにカーソルを合わせたときのツールバーに、最大 4 つのアクションを固定します。残りは … メニューに入ります。
- **ダブルクリックの動作:** メッセージをダブルクリックしたとき、To-Do リストに追加するかどうか。

## タスク

- **クイックタスク作成:** タスクテーブルのクイック追加の行で、プロジェクトの必須項目を求めるかどうか。
- **PRマージ時に自動Close:** プルリクエストがマージされたら、あなたのタスクを完了にします。GitHub の接続が必要です。
- **Googleカレンダーと自動同期:** 締切のあるタスクを、終日の予定として Google カレンダーに追加し、**既存のタスクを今すぐ同期する**ことができます。Google カレンダーの接続が必要です。

## 通知

メインのスイッチ、通知を一時停止、ブラウザーの許可、通知のグループ、メール通知、そしてミュートしたチャットと項目です。このマニュアルの通知のページを参照してください。

## メンショングループとカスタム絵文字

- **メンショングループ:** @design のような名前で、チャット、タスクのコメント、タスクの説明でメンションされると、グループの全メンバーに通知します。
- **カスタム絵文字:** チーム独自の絵文字です。名前には a-z、0-9、\_、+、- が使え、50 文字までです。ファイルは .png、.jpg、.gif、.webp、.svg で、512 KB までです。チームの誰でも追加できます。削除できるのは、アップロードした本人だけです。

## ショートカット

キーボードショートカットの一覧です。スポットライトと 7 つの文字キーのショートカットは変更できます。ショートカットのキーの表示を選び、Ctrl と Cmd(Windows/Linux では Ctrl と Alt)に英字か数字を組み合わせて押します。いつでも初期設定に戻せます。そのほかは固定です。このマニュアルの「キーボードショートカット一覧」のページをご覧ください。

## セキュリティ

2段階認証です。オンにすると、パスワードのあとに、認証アプリの 6 桁のコードを求められます。スマートフォンをなくしたときのために、リカバリーコードが発行されます。これはメールアドレスとパスワードでのサインインに適用されます。Google や GitHub でサインインしている場合は、そのアカウントで 2段階認証をオンにしてください。このマニュアルのセキュリティとサインインのページを参照してください。

## アカウント

- **データをエクスポート:** 自分が作成した内容を JSON ファイルとしてダウンロードします。
- **セキュリティ アクティビティ:** 最近のサインイン、サインアウト、データのエクスポート、連携したアカウントと API キー、そしてアカウントへのサインインの失敗が表示されます。
- **参加中のチーム:** チームから離れます。チームのオーナーの場合は、先にそのプロフィールからオーナー権限を譲渡してください。
- **アカウントを削除:** DELETE と入力します(アカウントにパスワードがある場合はパスワードも)。ほかのメンバーがいるチームのオーナーである間は、Genos はアカウントを削除しません。

## 連携

Google(Google カレンダー用)と GitHub を接続し、Genos が見られるリポジトリを選びます。このタブは、お使いの Genos で連携が有効な場合にだけ表示されます。

## Developer

AI を接続する(Claude または ChatGPT、Core 以上)、接続済みアプリ、個人の API キーです。キーを作成するときは、パスワードをもう一度求められます。チームのオーナーとエディターには、チームのキー、接続済みの AI アプリ、Webhook も表示されます。オーナーには、AIアプリの利用とセキュリティログも表示されます。Webhook は無料プランには含まれません。このマニュアルの接続のページを参照してください。

## あなたのプロフィール(設定の一部ではありません)

アバターをクリックして**マイプロフィール**を選ぶと、写真、名前、役職、ステータスを変更できます。アバターのステータスメニューからは、通知の一時停止や**常にオフラインにする**も選べます。

## 探しても見つからないもの

- サインイン中のパスワード変更: この操作の画面はありません。サインインのページにある、パスワードを忘れた場合のリンクを使ってください。
- メールアドレスの変更: アプリ内ではできません。
- タイムゾーンの選択: Genos は端末からタイムゾーンを読み取ります。「設定 > Genos > Genosが記憶していること > Genosが使う設定」で確認できます。
- タスクテーブルの列と並べ替え: これらは、設定ではなく、タスクテーブル自体の列の設定にあります。
