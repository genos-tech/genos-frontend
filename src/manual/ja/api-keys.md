## AI アプリを接続する(API キー不要)

Claude、ChatGPT などの AI アプリを接続するのに、キーは要りません。「設定 → Developer → 接続済みアプリ → **AI を接続する**」を開き、使うアプリを選んで、手順に従います。アプリは、あなたとして Genos にサインインします。承認ページで、アプリが使えるチームと、できること(読み取り、変更、そして最初はチェックが外れている削除)を選びます。そのあと**許可**を押します。接続には Core プラン以上が必要です。

貼り付けるアドレスは、そのパネルに表示されます。`https://<your Genos API address>/api/public/v1/mcp/core` のような形です。パスを含めて全体を貼り付け、後ろには何も付けないでください。

アプリのアクセスを終了するには、「設定 → Developer → 接続済みアプリ」を開き、**取り消す**を押します。次のリクエストから動かなくなります。各アプリの手順は「Genos を他のツールにつなぐ: API、MCP、リアルタイム」にあります。

## キーを作成する

1. 「設定 → Developer → APIキー」を開きます。
2. キーの用途を入力します。たとえば「CI ボット」。
3. Read か Read & write を選びます。
4. 有効期間(「有効期間」: 30、90、180、365 日)を選びます。初期値は 90 日で、1 年より長く使えるキーはありません。その後は、新しいキーを作ります。
5. Read & write のキーに限り、「取り消せない操作や、アクセス権を変更する操作(カレンダーの予定・マイルストーン・スプリント・ノート・ノートフォルダの削除、プロジェクトへのメンバー追加と参加リクエストの承認、ノートの共有)も許可する」にチェックを入れられます。これは、カレンダーの予定、マイルストーン、スプリント、ノート、ノートフォルダの削除、プロジェクトへのメンバー追加や参加リクエストの承認、ノートの共有を指します。初期状態ではオフです。キーが本当に必要とするとき以外は、オフのままにしてください。
6. **キーの作成**を押します。Genos はパスワードの再入力を求め(「ご本人確認」)、10 分間は再度求めません。Google や GitHub だけでサインインするアカウントにはパスワードがないので、求められません。

- キーが表示されるのは 1 回だけです(「今すぐ API キーをコピーしてください」)。保管する場所に、そのままコピーしてください。あとから読み返すことはできません。なくした場合は、取り消して、別のキーを作ってください。
- キーは `gnos_` で始まるので、ログの中でも見つけられます。一覧には、最初の数文字しか表示されません。
- アカウントでキーが作成されると、Genos からメールが届きます。心当たりがなければ、そのキーを取り消してください。
- キーはあなたとして動くので、あなたに見えるものはすべて、キーにも見えます。パスワードと同じように扱ってください。公開リポジトリや、ブラウザで動くコードには、決して入れないでください。
- キーを取り消すと、そのキーは次のリクエストからすぐに止まり、取り消したキーを再び有効にすることはできません。キーが漏れたと思ったときは、これが適切な対応です。
- すべてのキーに期限が必要になる前に作ったキーには、「無期限 — 新しいキーへの切り替えをおすすめします」と表示されます。新しいキーに置き換えてください。

## チームの API キー

チームキーは、あなたではなく 1 つのチームに紐づきます。作れるのは、チームのオーナーかエディターだけで、API から作ります。オーナーとエディターは、「チームの API キー」に、有効なチームキーが、作成者とともに一覧表示されます。オーナーは、どのチームキーでも取り消せます。エディターは、ビューアーのキーと自分のキーを取り消せます。チームキーは、作成者がチームを離れたときにも動かなくなります。

## キーを使う

ヘッダー `Authorization: ApiKey <your key>` を送ります。方式は ApiKey という語です。Bearer はアプリ自身のサインイン用で、ここでは拒否されます。また、キーでキーを作成したり削除したりはできないので、漏れたキーが自分のコピーを作ることはできません。

- `GET /api/public/v1/me/`: キーが誰として動くか、そのスコープとチームを返します。キーが使えることを確かめるには、ここから始めます。
- `GET /api/public/v1/projects/`: あなたのプロジェクト。
- `GET` と `POST /api/public/v1/tasks/`: タスクの一覧、または作成。
- `GET` と `PATCH /api/public/v1/tasks/<id>/`: 1 つのタスクの読み取り、または更新。
- `GET /api/public/v1/openapi.json`: 上記すべてを機械可読にした記述です。キーが要らない唯一のアドレスです。
- 各キーで、REST リクエストは 1 分あたり 120 回まで行えます。
- 個人用のキーは、1 つのチームではなくあなたに属するので、リクエストごとにどのチームかを示す必要があります。そのため、`me/` では、個人用のキーにチームが表示されません。チームキーは、自分のチームを持っています。

## プランごとの上限

- REST API のキーは、すべてのプランで使えます。
- MCP(あなたのキーを使う AI エージェント、または接続した AI アプリ)には、Core プラン以上が必要です。
- お使いの Genos では、AI アプリの利用をプランごとに制限することもあります。その制限がオンの場合、キーまたは接続したアプリごとの 1 分あたりの MCP 呼び出しは、Core で 60、Pro で 120、Max で 240 です。1 人あたりの 1 日の呼び出しは、3,000、10,000、30,000 です。有効な API キーと接続したアプリは、それぞれ 3、10、25 までです。拒否されるのは新しいものだけで、すでにあるものは動き続けます。

## Webhook

Webhook は、スクリプトがタイマーで確認する代わりに、何かが起きたときに Genos がサーバーへ知らせる仕組みです。「設定 → Developer → Webhook」で、チームのオーナーかエディターが追加します。

1. https のアドレスを入力します。公開されたアドレスでなければなりません。
2. 受け取るイベントにチェックを入れます: task.created、task.updated、task.completed、task.comment_created、message.created。
3. 任意: プロジェクトを選びます。何も選ばない場合は、すべてのプロジェクトが対象です。
4. message.created では、メッセージの本文があなたのアドレスに送られるため、監視するチャンネルを必ず選ぶ必要があります。何も選ばない場合、チャットのイベントは送られません。ダイレクトメッセージは、Webhook に送られることはありません。
5. **Webhook を追加する**を押します。Genos は、キーのときと同じようにパスワードの再入力を求め、Webhook が追加されたことをメールで知らせます。

- 署名シークレットが表示されるのは 1 回だけです(「今すぐ署名シークレットをコピーしてください」)。配信のたびに、X-Genos-Signature ヘッダーを確認するために使います。
- あなたのアドレスが 10 回続けて失敗すると、Genos は Webhook をオフにします。その場合は「失敗を繰り返すと無効化される」と表示されます。エンドポイントを直し、Webhook を削除して、もう一度追加してください。追加し直すと、新しいシークレットが作られます。
- Webhook はチームごとに数えます。無料は 0 件、Core は 3 件、Pro は 10 件、Max は 25 件です。チームのプランか、チームのオーナーのプランのうち、良いほうで決まります。無効になった Webhook も、削除するまで数に入ります。ダウングレードしても、既存の Webhook は配信を続けます。

## チームの視点(オーナーとエディター)

自分のキーの下には、「設定 → Developer」に、チームのオーナーとエディターに向けたセクションがいくつか表示されます。

- **チームの API キー**: このチームで動けるすべてのキー(上記を参照)。
- **接続済みの AI アプリ**: メンバーが接続した、このチームで作業できる AI アプリ。オーナーはどれでも終了でき、エディターはビューアーのものを終了できます。**このチームへのアクセスを終了**で外れるのは、このチームだけです。その人のほかのチームでは、引き続き動きます。
- **AIアプリの利用**(オーナーのみ): このチームで、各メンバーの AI アプリがどれだけ動いたかを、週ごとに表示します。件数だけで、何を読み、何を検索したかは表示されません。
- **セキュリティログ**(オーナーのみ): このチームでの重要な変更を、新しい順に表示します。メンバーの参加と退出、ロールとオーナー権限の変更、招待、API キー、Webhook、アラートが対象です。記録は 365 日間保管されます。

## まだ存在しないもの

- 公開リンク。ワークスペースの中のものは、サインインして許可された人でなければ開けません。どこに貼ったリンクも、読む人のアクセス権を確認します。
- スプレッドシートへのエクスポート。「設定 → アカウント →**データをダウンロード**」で、自分のデータを JSON としてエクスポートでき、ノートはメニューから Markdown としてエクスポートできます。タスクやチャットの CSV エクスポートはありません。
- Slack、Notion、Jira、Asana とのライブの連携。連携は Google と GitHub の 2 つです。CSV、Jira、Notion のエクスポートからはタスクを、Notion のエクスポートフォルダからはノートを、そして(チームのオーナーなら)Slack のエクスポートをグループチャットとして、インポートできます。
