## 通知

- **まったく届かない**: 「設定 → **通知**」を開きます。ウェブ通知がオンで、通知が一時停止になっていないか確認してください(アバターに月のマークが付いていれば、一時停止中です)。次に**ブラウザの許可**を確認します。ブラウザが Genos をブロックしている場合は、アプリ内のどの設定でも上書きできません。
- **iPhone に届かない**: iOS は、インストールしたアプリにしか通知を配信しません。Safari で共有をタップして「ホーム画面に追加」を選び、ホーム画面から Genos を開いてサインインし、通知を許可してください。
- **特定の会話だけ静か**: ミュートされている可能性があります。「設定 → **通知**」に、ミュート中のチャットと項目(スレッド、タスク、ノート)が一覧表示されます。そこからミュートを解除してください。
- **メールが多すぎる**: メールには、アプリ内通知やデスクトップ通知とは別に、専用のスイッチとカテゴリーがあります。通知メールには、どれも配信停止のリンクも付いています。
- **デスクトップ通知ではなくトーストが出る**: これは仕様です。Genos のタブが手前にあるときは、アプリ内のトーストが表示されます。デスクトップ通知は、タブがバックグラウンドにあるときのものです。

## アクセス

- **プロジェクトやノートが開かない**: メンバーではない可能性があります。用意されている場合は、アクセスのリクエストを使ってください。オーナーが受信箱から承認または拒否します。
- **誰も招待できない**: 招待にはチームのオーナーかエディターの権限が必要です。オーナーに、あなたをエディターにしてもらってください。
- **オーナーから反応がない**: エディターは、チームプロフィールで**オーナー権限をリクエスト**を選べます。オーナーが 30 日以内に返答しない場合、エディターは**オーナー権限を取得**を選べます。
- **招待リンクが使えない**: 招待は、送られたメールアドレスでしか使えず、7 日で期限が切れます。別のアカウントでサインインしている場合は、**サインアウトして続ける**を選びます。期限が切れていたら、新しい招待を依頼してください。
- **アカウントを削除できない**: 他のメンバーがいるチームのオーナーのままになっています。そのチームのチームプロフィールからオーナー権限を移したうえで、削除してください。

## 「現在のプランでは利用できません」

- **AI アプリの接続で「現在のプランでは利用できません」と出る**: AI アプリの接続は Core から使えます。「設定 → **プランと使用状況**」を参照してください。
- **接続したアプリが「一時停止中」と表示される**: 現在のプランには、連携アプリが含まれていません。アプリは一覧に残り、Core 以上にすると再び動きます。
- **スケジュールが、プランが原因で停止していると表示される**: 定期レポートは Core から使えます。スケジュールは保持され、アップグレードすると再開します。
- **「チームのプランには Webhook が含まれていません」**: Webhook は Core から使えます。チームのプランか、チームのオーナーのプランのどちらかが対象になります。
- **HTML ページをインポートできない**: HTML ページは Core から使えます。プランのサイズ上限を超えるページや、HTML の保存容量を超えることになるページも受け付けられません。
- **「プランで保存できるスキルは … 件までで…」**: スキルを削除するか、アップグレードしてください。
- **Effort のレベルに「アップグレードしてロックを解除する」と表示される**: 無料は低まで、Core は中まで、Pro 以上は高まで使えます。
- **"You've created all … for this month"**: 月ごとのタスクまたはノートの上限に達しました。毎月 1 日(UTC)にリセットされます。

## Genos と AI クレジット

- **クレジットがなくなった**: Genos は「AIクレジットを使い切ったため、現在Genosは回答できません。」と表示します。期限のないパックを買うには**クレジットを購入**、または**プランをアップグレード**を選びます。月ごとのクレジットは、毎月 1 日(UTC)にリセットされます。「設定 → **AIクレジット利用**」で、何に使ったかを確認できます。
- **長い回答が途中で止まった**: リクエストの途中で残高が少なくなりました。クレジットを購入するか、月ごとのリセットを待ってください。
- **今日の質問回数を使い切った**(Genos がクレジットを使わない設定の場合): 回数は UTC の 0 時にリセットされます。「設定 → **プランと使用状況**」で現在の状況を確認できます。
- **作ったばかりのものが見つからない**: インデックスの作成に少し時間がかかります。しばらくしてからもう一度お試しください。
- **自分に見えるものが Genos に見えないと言われる**: 正しいチームにいるか確認してください。チームごとにコンテンツは別々です。ブラウザで同時に有効にできるチームは 1 つだけです。別のタブで別のチームにサインインしたと表示されたタブは、再読み込みしてください。
- **古い情報をもとに回答された**: 使われたノートを直してください。回答はノートに従います。
- **プロバイダーが「Soon」と表示される**: そのプロバイダーは、まだ提供されていません。

## サインイン

- **パスワードを忘れた**: サインインのページで**パスワードをお忘れですか？**を選び、メールのリンクを使います。これは、メールとパスワードでサインインするアカウントにだけ使えます。Google や GitHub のアカウントには Genos のパスワードがないので、そのプロバイダーでサインインしてください。
- **「誤ったコードが多すぎます」**: 2 段階認証のコードを 5 回続けて間違えると、アカウントは 15 分間ロックされます。その後も間違えるたびに待ち時間が長くなり、最長 24 時間になります。待ってから、もう一度お試しください。
- **「サインインの有効期限が切れました」**: コードの入力は、パスワードを入力してから数分以内に行う必要があります。もう一度パスワードを入力してください。
- **スマートフォンをなくした**: コードの入力画面で**リカバリーコードを使う**を選び、リカバリーコードのどれか 1 つを入力します。各コードは 1 回だけ使えます。そのあと「設定 → **セキュリティ**」を開き、**オフにする**から**オンにする**を選んで新しいスマートフォンを設定し、新しいリカバリーコードを保存してください。
- **スマートフォンもリカバリーコードもなくした**: サポートにメールしてください。サポートは、アカウントがあなたのものであることを確認してから、2 段階認証をオフにします。

## そのほか

- **アップロードが拒否された**: ファイルが、プランのファイルごとのサイズ上限を超えています。
- **ページが古いまま、またはボタンが反応しない**: タブを再読み込みしてください。何日も開いたままのタブは、開いた時点のコードのまま動き続けます。
- **ノートの内容を誤って消してしまった**: ノートの履歴を開き、以前のバージョンを復元してください。
- **アプリ内ガイドを削除してしまい、元に戻したい**: 自動では再作成されません。サポートに復元を依頼してください。
- それでも解決しない場合: genos.support@genosai.dev
