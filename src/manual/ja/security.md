## 2段階認証

2段階認証をオンにすると、Genos はパスワードのあとに、認証アプリの 6 桁のコードを求めるようになります。パスワードが盗まれたり推測されたりしても、それだけではアカウントを開けなくなります。

- メールアドレスとパスワードでサインインするときに適用されます。Google や GitHub でサインインする場合は、そちらのアカウントで 2段階認証をオンにしてください。Genos 側で設定することはありません。
- オンにするまでは、オフの状態です。

オンにするには:

1. 「設定 > **セキュリティ**」を開き、**オンにする**を選びます。
2. パスワードを入力します。
3. 認証アプリ(Google Authenticator、1Password、Authy など、6 桁のコードを作れるアプリ)で QR コードをスキャンします。スキャンできない場合は、セットアップキーをアプリに入力します。
4. アプリに表示される 6 桁のコードを入力します。コードは 30 秒ごとに変わります。
5. 10 個のリカバリーコードを保存します(**すべてコピー**または**ダウンロード**)。「コードを保存しました」で確認し、**完了**を選びます。表示されるのはこの 1 回だけです。パスワードとは別の場所に保管してください。

サインインするときは、アプリのコードを入力します。スマートフォンが手元にないときは、**リカバリーコードを使う**を選びます。リカバリーコードは、1 つにつき 1 回だけ使えます。残りの数は、「設定 > **セキュリティ**」で確認できます。**新しいリカバリーコードを取得**を使うと、セット全体が入れ替わり、古いコードは使えなくなります。

**オフにする**、**オンにする**、**新しいリカバリーコードを取得**は、いずれもパスワードを求められます。

コードを 5 回続けて間違えると、アカウントが 15 分間ロックされます。その後に間違えるたびに待ち時間が長くなり、最長で 24 時間になります。

## スマートフォンをなくしたとき

1. パスワードでサインインし、**リカバリーコードを使う**を選んで、コードのひとつを入力します。
2. 「設定 > **セキュリティ**」を開き、**オフにする**を選び、新しいスマートフォンでもう一度**オンにする**を選びます。
3. 新しいリカバリーコードを保存します。

リカバリーコードもなくした場合は、genos.support@genosai.dev にメールしてください。サポートがアカウントの持ち主であることを確認したうえで、2段階認証をオフにします。そのあとはパスワードでサインインでき、設定し直せます。

## パスワードを再度求められるとき

API キーや Webhook を追加する前、AI アプリを接続する前、接続済みのアプリにより多くのアクセスを与える前に、Genos はパスワードを求めます(「ご本人確認」)。そのあと 10 分間は、もう一度求められることはありません。Google や GitHub でサインインするアカウントには入力するパスワードがないので、求められません。

また、アカウントで API キー、Webhook、AI アプリの接続が作成されるたびに、Genos は登録したメールアドレスにメールを送ります。

## パスワードとメールアドレス

- サインインしたままパスワードを変更する方法はありません。ログアウトし、サインインページで**パスワードをお忘れですか？**を選び、メールのリンクを使ってください。これは、メールアドレスとパスワードでサインインするアカウントだけで使えます。
- パスワードをリセットすると、すべての場所でサインアウトされます。接続済みの AI アプリと API キーも終了します。必要になったら、アプリを接続し直し、新しいキーを作成してください。
- メールアドレスは、アプリ内では変更できません。

## 何が起きたかを確認する

- **セキュリティ アクティビティ**(「設定 > **アカウント**」): 最近のサインイン、サインアウト、データのエクスポート、接続したアカウントと API キーに加え、あなたのアカウントへのサインインの失敗が表示されます。身に覚えのないものがあれば、パスワードをリセットしてください。
- **セキュリティログ**(「設定 > **Developer**」、チームのオーナーのみ): チームへの重要な変更が、新しい順に並びます。メンバーの参加と脱退、ロールとオーナー権限の変更、招待、API キー、Webhook、アラートです。記録は 365 日間保存されます。

## アカウントのエクスポートと削除

- **データをエクスポート**(「設定 > **アカウント** > **データをダウンロード**」): あなたが作成したすべて(プロフィール、ノート、To-Do、タスク、メッセージ、コメント)の JSON ファイルです。他の人が書いたチームのコンテンツは含まれません。
- **アカウントを削除**(「設定 > **アカウント** > **アカウントを削除**」): DELETE と入力し、パスワードがあるアカウントではパスワードも入力します。名前、メールアドレス、プロフィールが消去され、すべての場所でサインアウトされます。非公開のノート、To-Do、AI の履歴は削除されます。あなたが最後のメンバーだったチームは閉鎖されます。チームメイトと一緒に行った作業は、相手のワークスペースに「削除済みユーザー」として残ります。この操作は元に戻せません。
- 他のメンバーがいるチームのオーナーである間は、アカウントを削除できません。先に、各チームのプロフィールからオーナー権限を譲渡してください。1 つのチームだけを抜けて他は残したいときは、「設定 > **アカウント**」の**参加中のチーム**を使います。
