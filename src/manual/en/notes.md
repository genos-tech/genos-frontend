## Where notes live

- **My Notes**: private to you. Organize them with folders and subfolders.
- **Team Notes**: team folders. Each folder sets who can use it. **Open to the team** means any teammate can read and write in it. **Restricted** limits it to the people you choose. A subfolder can inherit its parent's setting, and every note inside follows its folder.
- **Shared with me**: notes other people shared with you.
- **Task notes**: attached to a task. Members of the project can read and edit them, so plans live next to the work.
- **Chat notes**: attached to a chat or thread, for shared minutes and decisions. People in the chat can read and edit them.
- Star notes and folders to add them to **Favorites**.

## Editing

- The editor is a block editor. It has headings, bulleted and numbered lists, checkboxes, code blocks, tables and images. You can @-mention people and leave comments on text.
- Notes are edited together in real time. Several people can edit at once and see each other's changes as they happen.
- **Version history** keeps earlier versions. Pick one to preview it, and restore it if needed. Restoring adds a new version, so nothing is lost. Only the note's owner and editors can restore.
- **Note templates:** team templates appear next to the built-in ones in the New note menu. A template can be the default for a folder.

## Import and export

- **Import Markdown…** creates a note from a .md file. Choose **Whole folder** to import a folder tree, such as a Notion export. Every subfolder becomes a note folder, every Markdown file becomes a note, and images come along.
- When your Genos has HTML pages turned on, the same dialog also takes a .html file and saves it as an HTML page.
    - The page is shown in a sandbox, and you can't edit it in the note editor.
    - Parts the sandbox blocks, such as scripts or styles loaded from other addresses, are listed when you import.
    - HTML pages need the Core plan or higher, and each plan has a size limit.
- **Export as Markdown** saves one note. **Export folder as .zip** saves a whole folder as Markdown files with their images, and the zip can be imported back.

## Sharing and access

- Use **Share** on a note to add teammates as **Editor** (can change the note) or **Viewer** (can only read). Only the owner can add or remove people.
- If you open a note you can't see, use **Request Access**. The owner gets the request in their Inbox and can approve it there.
- Search (Cmd+K or Ctrl+K) covers every note you can read.
